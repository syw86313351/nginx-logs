### 3.2 通信流向

#### 公网VLAN (VLAN 10)
- **来源**：防火墙（USG6305E）
- **汇聚点**：每个机柜的千兆交换机（公网端口）
- **作用**：外部用户访问通道
- **IP**：由ISP分配

#### 广州开心网络 (VLAN 20)
- **来源**：千兆交换机
- **用途**：与广州开心网络专线互联
- **配置**：IP段待确认，通常通过运营商分配
- **应用**：专用业务网络通道

#### 业务网络 (10.0.0.0/24 - VLAN 30)
- **来源**：千兆交换机
- **连接**：业务服务器/应用系统
- **用途**：内部业务系统通信
- **网关**：10.0.0.1

#### 管理网络 (192.168.1.0/24 - VLAN 40)
- **来源**：千兆交换机
- **连接**：交换机、防火墙等设备管理接口（**不含华为存储**）
- **用途**：运维人员远程管理和监控
- **网关**：192.168.1.1

#### 存储网络 (万兆 - 不需要VLAN)
- **连接方式**：万兆交换机双链路
- **冗余机制**：两条万兆链路并行，任一链路故障不影响存储访问
- **传输速率**：10Gbps，满足存储高速读写需求

## 六、存储连接详解（重点）

### 6.1 双链路架构

```
┌──────────────────────┐
│     华为存储          │
│   (每机柜1台)        │
│  ┌──────┬──────┐    │
│  │存储NIC1│存储NIC2│    │
│  └───┬──────┬───┘    │
└──────┼──────┼────────┘
       │      │
       │      │
    ┌──▼──┐  ┌──▼──┐
    │万兆▼兆 │  │万兆▼兆 │
    │交换机1│  │交换机2│
    │      │  │      │
    └──────┘  └──────┘
```

### 6.2 链路特性

- **链路1**：存储 → 万兆交换机#1
  - 速率：10Gbps
  - 用途：数据读写
  - 故障时自动切换

- **链路2**：存储 → 万兆交换机#2
  - 速率：10Gbps
  - 用途：备份/冗余
  - 互为热备份

### 6.3 工作模式

1. **主用模式**：
   - 所有I/O流量通过链路1
   - 链路2处于待命状态

2. **故障转移**：
   - 链路1故障 → 自动切换到链路2
   - RTO (恢复时间目标)：秒级
   - 无数据丢失

3. **带宽利用**：
   - 单链路故障：仍可维持10Gbps
   - 双链路正常：可配置为负载均衡(各5Gbps) 或 主备模式(单条10Gbps)

## 七、配置建议

### 7.1 存储网络配置

1. **网络分离**：万兆存储网络与业务网络完全分离，避免业务流量影响存储性能
2. **IP配置**：存储可使用单独的私有网段（如172.16.0.0/16）
3. **链路聚合**：根据存储支持情况，可配置LACP链路聚合以提升带宽利用

### 7.2 千兆网络配置

1. **VLAN隔离**：
   - 公网VLAN：独立隔离，防止内部网络暴露
   - 业务VLAN：用于应用间通信
   - 管理VLAN：仅允许运维IP段访问

2. **QoS策略**：为不同VLAN配置QoS保证关键业务带宽

3. **访问控制**：在千兆交换机配置ACL，限制各VLAN间通信

### 7.3 防火墙策略

1. **区域划分**：
   - Trust区：内网业务网（10.0.0.0/24）
   - DMZ区：公网VLAN（可选，根据应用场景）
   - Untrust区：Internet

2. **路由策略**：
   - 入站：仅允许特定端口和应用
   - 出站：根据业务需求制定

3. **日志审计**：启用安全日志记录所有重要流量

### 7.4 监控告警

1. **监控对象**：
   - 万兆链路状态（光口信号、丢包率）
   - 千兆交换机VLAN状态和流量统计
   - 防火墙连接数、吞吐量、安全事件
   - 存储网络延迟和丢包

2. **告警阈值**：
   - 链路故障：立即告警
   - 链路利用率 > 80%：告警
   - 丢包率 > 0.1%：告警

## 八、故障恢复场景

### 8.1 单链路故障

**场景**：万兆链路1故障
- **系统表现**：存储自动切换至链路2，业务不中断
- **恢复时间**：秒级自动转移，无需人工干预
- **影响范围**：仅影响该机柜的存储访问，不影响其他机柜

### 8.2 交换机故障

**场景**：千兆交换机故障
- **影响**：该机柜的业务网络中断
- **恢复方式**：更换交换机或切换备用设备
- **预防方案**：建议配置备用千兆交换机

**场景**：万兆交换机故障
- **影响**：如为双链路中一条，系统自动转移；如两条均故障，存储无法访问
- **恢复方式**：立即更换故障交换机

### 8.3 防火墙故障

**场景**：USG6305E故障
- **影响**：所有外网访问中断，内网可能仍可通信
- **恢复方案**：
  - 短期：配置备用防火墙进行HA
  - 长期：建议部署防火墙集群

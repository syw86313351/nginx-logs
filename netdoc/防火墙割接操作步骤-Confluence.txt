h1. USG6305E 防火墙割接 — 实施步骤（双方案）

{toc:outline=true|style=disc|maxLevel=3}

本页将防火墙割接拆分为 *两套独立、可单独执行* 的完整流程。实施前请先选定方案，全程按所选方案执行，勿混用。

----

h2. 方案对比与选型

|| 对比项 || 方案一 || 方案二 ||
| {{GE0/0/7}} 地址 | {{10.0.0.11/24}} | {{10.0.0.254/24}} |
| 业务机改网关 | *否* — {{ws4}}、{{ws8}}、{{ws11~ws19}} 保持 {{10.0.0.11}} | *是* — 上述 *11 台* 改默认网关为 {{10.0.0.254}} |
| {{ws6}} 默认网关 | {{10.0.0.11}} | {{10.0.0.254}} |
| 适用场景 | 防火墙占用原网关 IP，业务机零改动 | 防火墙使用独立网关 IP，需逐台改 11 台主机 |
| 割接复杂度 | 较低 | 较高（含 11 台改网关与验收） |

{info:title=技术口径（两方案一致）}
* *{{XGE0/0/0}}* = 西信 WAN {{182.140.240.121/25}}，下一跳 {{182.140.240.1}}
* *{{GE0/0/7}}* = 业务网 {{10.0.0.0/24}}（方案一 {{.11}} / 方案二 {{.254}}）
* *{{GE0/0/0}} + {{GE0/0/1}}* 极云透传 *全程不动*；A 组公网配置不变
* *{{ws6}}*：{{10.0.0.16}}，割接后出/入站均经防火墙 NAT
* *B 组 DNAT*：自 {{ws1}} 迁移至防火墙，逐条拨测后停 {{ws1}} NAT
{info}

{warning:title=割接全程勿动}
* {{GE0/0/0}} + {{GE0/0/1}}：极云入网 / 公网透传
* A 组公网服务器配置不变
* 公网 IP {{182.140.240.121}} 仅出现在防火墙 {{XGE0/0/0}}，勿在业务机保留
{warning}

h1. 方案一：防火墙 {{GE0/0/7}} 使用 {{10.0.0.11}}

{note}
本方案防火墙业务口占用原网关 IP {{10.0.0.11}}，{{ws4}}、{{ws8}}、{{ws11~ws19}} 共 11 台 *无需改默认网关*。
{note}

h2. 1. 割接前准备（约 30 分钟）

* ( ) 导出防火墙全量配置（含 NAT、路由、安全策略）
* ( ) {{ws1}}：{{iptables -t nat -L -n -v}}（B 组 DNAT 对照源）
* ( ) {{ws6}}：{{ip addr}}、{{ip route}}、{{ss -lntp}}（入站端口对照表）
* ( ) 接线：西信线 → {{XGE0/0/0}}；{{GE0/0/7}} → 三柜千兆 {{VLAN30}} 业务网
* ( ) 确认 {{ws6}} {{Gb1}} 公网 {{182.140.240.121}} 待删除
* ( ) 确认 {{ws4}}、{{ws8}}、{{ws11~ws19}} 现网默认网关均为 {{10.0.0.11}}（本方案割接后保持不变）
* ( ) 维护窗口开始，再次备份防火墙与 {{ws1}}/{{ws6}} 状态

h2. 2. 防火墙配置（严格按序）

h3. (1) {{XGE0/0/0}} — 西信 WAN

*菜单*：{{网络 → 接口 → XGE0/0/0 → 编辑}}

|| 项 || 值 ||
| 模式 | 路由（{{undo portswitch}}） |
| 安全域 | {{untrust}} |
| IPv4 | {{182.140.240.121}} / {{255.255.255.128}} |
| 下一跳 | {{182.140.240.1}}（仅防火墙 WAN，勿下发给服务器） |
| DNS | {{61.139.2.69}}（可选） |

{code:title=CLI 参考|language=bash}
interface XGigabitEthernet0/0/0
 undo portswitch
 description XiXin-Telecom-WAN
 ip address 182.140.240.121 255.255.255.128
ip route-static 0.0.0.0 0.0.0.0 182.140.240.1
{code}

*验证*：墙内 {{ping 182.140.240.1}}、{{ping}} 外网（如 {{223.5.5.5}}）

h3. (2) {{GE0/0/7}} — 业务网 {{10.0.0.0/24}}

*菜单*：{{网络 → 接口 → GE0/0/7 → 编辑}}

|| 项 || 值（方案一） ||
| 模式 | 路由（{{undo portswitch}}） |
| 安全域 | {{trust}} |
| IPv4 | {{10.0.0.11/24}} |
| 禁止 | 勿配任何 {{182.140.240.x}} |

{code:title=CLI 参考|language=bash}
interface GigabitEthernet0/0/7
 undo portswitch
 description VLAN30-Biz-10.0.0.0
 ip address 10.0.0.11 255.255.255.0
{code}

*验证*：接口 Up；后续业务机可 {{ping 10.0.0.11}}

h3. (3) {{ws6}} 出网

*菜单*：{{策略 → 策略路由}}、{{策略 → NAT策略 → 源NAT}}、{{策略 → 安全策略}}

|| 项 || 配置 ||
| 源地址 | {{10.0.0.16/32}} |
| 出接口 | {{XGE0/0/0}} |
| 源 NAT | 转换为 {{182.140.240.121}} |
| 安全策略 | {{trust}} → {{untrust}} 放行所需服务 |

h3. (4) {{ws6}} 入站（目的 NAT）

*菜单*：{{策略 → NAT策略 → 目的NAT}} / {{NAT服务器}}

|| 外部 || 内部 ||
| {{182.140.240.121:端口}} | {{10.0.0.16:端口}} |

{note}
端口以 {{ws6}} 割接前 {{ss -lntp}} 导出为准，逐条对照配置。
{note}

h3. (5) B 组 DNAT（自 {{ws1}} 迁移）

# 在 {{ws1}} 导出 {{iptables -t nat}}
# 在防火墙上 *逐条* 新建目的 NAT
# *每条* 外网拨测通过后再迁下一条
# 全部完成后再停 {{ws1}} NAT（见 §4）

h3. (6) 保存配置

* ( ) {{系统 → 配置 → 保存}}
* ( ) 再次导出防火墙配置文件（割接后版本）

h2. 3. 改 {{ws6}}

{warning:title=注意}
公网 IP 只能出现在 {{XGE0/0/0}}；{{ws6}} {{Gb1}} 若仍保留 {{182.140.240.121}} 会导致 ARP/路由冲突。
{warning}

* ( ) {{Gb1}}：删除公网 IP {{182.140.240.121}}（可 down 接口）
* ( ) {{Gb2}}：{{10.0.0.16/24}}
* ( ) 默认网关：{{10.0.0.11}}（方案一）
* ( ) DNS：{{61.139.2.69}}
* ( ) {{ping 10.0.0.11}} 网关可达
* ( ) {{curl ifconfig.me}} → 源地址应为 {{182.140.240.121}}
* ( ) 外网访问 {{182.140.240.121}} 映射端口，入站正常

h2. 4. 切 B 组

* ( ) B 组 DNAT 在防火墙上 *全量* 配置完成
* ( ) 逐条外网拨测 B 组映射端口，全部 OK
* ( ) 停止 {{ws1}} NAT 进程（{{Gb2}} 网卡 *保持 up*）
* ( ) *方案一无需改网关* — {{ws4}}、{{ws8}}、{{ws11~ws19}} 保持 {{10.0.0.11}}
* ( ) 抽查上述主机 {{ping}} 外网、业务访问正常

h2. 5. 验收（全部通过方可结束维护）

* ( ) {{XGE0/0/0}} 出网正常（{{ping 182.140.240.1}}、外网）
* ( ) {{GE0/0/7}}（{{10.0.0.11}}）与 {{ws4/ws6/ws8/ws11~19}} 互通
* ( ) {{ws6}} 本机无 {{182.140.240.121}}，出入站正常
* ( ) {{ws4/ws8/ws11~19}} 出网正常（网关仍为 {{10.0.0.11}}）
* ( ) A 组公网（极云 {{GE0/0/0}}、{{GE0/0/1}} 透传）正常
* ( ) 无双 NAT（{{ws1}} NAT 已停、防火墙策略生效）

h2. 6. 回退

|| 现象 || 处理 ||
| B 组业务异常 | 启 {{ws1}} NAT；暂禁防火墙对应 DNAT |
| 防火墙配乱 / A 组断网 | 导入割接前配置；核对 {{GE0/0/0/1}} 未动 |
| {{ws6}} 异常 | 恢复 {{Gb1}} 公网 {{182.140.240.121}} + 改前路由（用割接前备份） |
| 其他单机网络异常 | 核对 IP/网关/DNS，必要时重启网络服务 |

{panel:title=方案一推荐时间线|borderStyle=solid}
|| 时段 || 动作 ||
| T+0 | 维护开始、再备份 |
| T+15~45 | 完成 §2 防火墙配置并保存 |
| T+45~60 | 改 {{ws6}}、验证出网/入站 |
| T+60~120 | 迁移 B 组 DNAT、停 {{ws1}} NAT |
| T+120~180 | 全量验收 §5，观察 30~60 分钟 |
{panel}

================================================================================
  USG6305E 防火墙割接 — 实施步骤（简版）
================================================================================

【先定方案】
  甲：GE0/0/7 = 10.0.0.11  →  ws4/ws8/ws11~19 网关不改
  乙：GE0/0/7 = 10.0.0.254  →  上述 11 台改网关

【不动】GE0/0/0 + GE0/0/1 极云透传 · A 组公网

【分工】XGE0/0/0 = 西信 WAN (182.140.240.121) · GE0/0/7 = 10.0.0.0/24 网关

--------------------------------------------------------------------------------
1. 割接前（30 分钟）
--------------------------------------------------------------------------------
[ ] 导出防火墙配置、ws1 iptables -t nat -L -n -v、ws6 的 ip addr/route/ss -lntp
[ ] 西信线 → XGE0/0/0；GE0/0/7 → VLAN30 业务网
[ ] 确认 ws6 Gb1 公网待删除；11 台现网网关均为 10.0.0.11

--------------------------------------------------------------------------------
2. 防火墙配置（按顺序）
--------------------------------------------------------------------------------

(1) XGE0/0/0 — 西信 WAN
    路由模式 · untrust · 182.140.240.121/25 · 下一跳 182.140.240.1
    验证：墙内 ping 182.140.240.1、ping 外网

(2) GE0/0/7 — 业务网
    路由模式 · trust · 10.0.0.11/24（甲）或 10.0.0.254/24（乙）
    验证：接口 Up；勿配 182.140.240.x

(3) ws6 出网
    策略路由：源 10.0.0.16 → 出接口 XGE0/0/0
    源 NAT：10.0.0.16 → 182.140.240.121
    安全策略：trust → untrust 放行

(4) ws6 入站
    目的 NAT：182.140.240.121:端口 → 10.0.0.16:端口（按现网端口表）

(5) B 组 DNAT
    对照 ws1 iptables，在防火墙上逐条迁移；每条外网拨测通过再继续

(6) 保存配置并再导出一份

--------------------------------------------------------------------------------
3. 改 ws6
--------------------------------------------------------------------------------
[ ] Gb1 去掉 182.140.240.121
[ ] Gb2：10.0.0.16/24，网关 10.0.0.11（甲）或 .254（乙），DNS 61.139.2.69
[ ] ping 网关 · curl ifconfig.me 源地址应为 182.140.240.121
[ ] 外网访问 182.140.240.121 映射端口

--------------------------------------------------------------------------------
4. 切 B 组
--------------------------------------------------------------------------------
[ ] B 组 DNAT 全量拨测 OK 后，停 ws1 NAT（Gb2 保持 up）
[ ] 方案乙：ws4/ws8/ws11~19 网关改为 10.0.0.254（建议逐台）

--------------------------------------------------------------------------------
5. 验收（全过才结束）
--------------------------------------------------------------------------------
[ ] XGE 出网正常 · GE7 与业务机互通
[ ] ws6 无私网 IP · 出入站正常
[ ] ws4/ws8/ws11~19 出网正常
[ ] A 组公网（极云）正常
[ ] 无双 NAT

--------------------------------------------------------------------------------
6. 回退（出问题按轻重选）
--------------------------------------------------------------------------------
  单机网关改坏     → 改回 10.0.0.11
  B 组业务异常     → 启 ws1 NAT，暂禁防火墙对应 DNAT
  防火墙配乱/A组断 → 导入割接前配置，核对 GE0/0/0/1 未动
  ws6 异常         → 恢复 Gb1 公网 + 原路由（用改前备份）

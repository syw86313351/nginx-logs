## 二、接口配置

**入口：** 网络 → 接口

> 截图：接口列表页面

---

### 2.1 GE0/0/2 — 极云2（182.140.146.128）

点击 `GE0/0/2` 右侧 **编辑**

| 参数 | 填写值 |
|------|--------|
| 连接类型 | 静态 IP |
| IP 地址 | 182.140.146.128 |
| 子网掩码 | 255.255.255.0 |
| 安全域 | untrust |

点击 **确定**

---

| 子网掩码 | 255.255.255.128 |

## 三、路由配置

**入口：** 网络 → 路由 → 静态路由

> 截图：静态路由列表页面

### 3.1 主路由 — 西信 XGE0/0/0

点击 **新建**

| 参数 | 填写值 |
|------|--------|
| 目的地址/掩码 | 0.0.0.0 / 0 |
| 下一跳 | 182.140.240.1 |
| 出接口 | XGE0/0/0 |
| 优先级（preference） | 60 |

点击 **确定**

> 截图：主路由新建页面（填写完成）

### 3.2 备路由 — 极云2 GE0/0/2

点击 **新建**

| 参数 | 填写值 |
|------|--------|
| 目的地址/掩码 | 0.0.0.0 / 0 |
| 下一跳 | 182.140.146.129 |
| 出接口 | GE0/0/2 |
| 优先级（preference） | 80 |

点击 **确定**

> 截图：备路由新建页面（填写完成）

> 截图：路由列表，确认两条默认路由均存在

## 四、NAT 策略

**入口：** 策略 → NAT 策略 → 源 NAT

> 截图：源 NAT 策略列表

### 4.1 西信出口 NAT

点击 **新建**

| 参数 | 填写值 |
|------|--------|
| 名称 | NAT_XSX |
| 源安全域 | trust |
| 目的安全域 | untrust |
| 源地址 | 10.0.0.0 / 255.255.255.0 |
| 出接口 | XGE0/0/0 |
| 动作 | Easy IP |

点击 **确定**

> 截图：NAT_XSX 规则页面（填写完成）

### 4.2 极云2 出口 NAT

点击 **新建**

| 参数 | 填写值 |
|------|--------|
| 名称 | NAT_JY2 |
| 源安全域 | trust |
| 目的安全域 | untrust |
| 源地址 | 10.0.0.0 / 255.255.255.0 |
| 出接口 | GE0/0/2 |
| 动作 | Easy IP |

点击 **确定**

> 截图：NAT_JY2 规则页面（填写完成）

> 截图：NAT 策略列表，确认两条规则均启用

## 五、安全策略

**入口：** 策略 → 安全策略

> 截图：安全策略列表

### 5.1 内网访问公网

点击 **新建**

| 参数 | 填写值 |
|------|--------|
| 名称 | TRUST_TO_UNTRUST |
| 源安全域 | trust |
| 目的安全域 | untrust |
| 源地址 | 10.0.0.0 / 255.255.255.0 |
| 动作 | 允许 |

点击 **确定**

> 截图：TRUST_TO_UNTRUST 规则页面（填写完成）

### 5.2 内网管理设备

点击 **新建**

| 参数 | 填写值 |
|------|--------|
| 名称 | TRUST_TO_LOCAL |
| 源安全域 | trust |
| 目的安全域 | local |
| 源地址 | 10.0.0.0 / 255.255.255.0 |
| 服务 | HTTPS、SSH、ICMP |
| 动作 | 允许 |

点击 **确定**

> 截图：安全策略列表，确认规则均启用

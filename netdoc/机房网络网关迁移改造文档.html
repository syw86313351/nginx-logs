华为 USG6305E · C06/D03/D04 · 版本 3.0 · 2026-05-28

汇报结论（领导速览）

核心改造

防火墙承接 B 组出网（GE0/0/7 接 10.0.0.0/24）；GE0/0/0 极云入网不动，XGE0/0/0 西信电信 WAN（182.140.240.121）。网关二选一：10.0.0.11 或 10.0.0.254。详见 网关方案。

不改什么

A 组公网（ws1/2/3/5/6/7、dev、dev-2）出网路径不变；ws1 业务网卡（Gb2）无需停用，两种方案均保持网卡在线。

预期收益

去除 ws1 NAT 单点，B 组经防火墙统一策略出网；方案甲割接最快（零改主机网关），方案乙网关地址独立便于长期规划。

风险与控制

主要风险是现场参数不一致（公网 IP、VLAN ID、端口号）。控制策略：先灰度 1~2 台验证，再分批迁移；若异常，单台改回旧网关即可恢复。

风险等级

中等可控

前提：严格执行割接前核对清单。

0.1 防火墙业务网关方案（二选一）

迁移目标：由 华为 USG6305E 承接原 ws1（10.0.0.11）上的 B 组 NAT/网关职能；西信电信新线路经 XGE0/0/0 直连骨干，业务网经 GE0/0/7 接入 10.0.0.0/24（见 0.2.3、0.2.4）。以下两种方案择一实施；无论选哪种，ws1 的 Gb2 业务网卡均无需停机或拔线。

方案甲 · 推荐（割接量小）

防火墙网关 = 10.0.0.11

10.0.0.11 / 24

  • 在防火墙 GE0/0/7（路由口，接 10.0.0.0/24 业务网）配置网关地址 10.0.0.11，承接原 ws1 DNAT/SNAT 能力。
  • ws4、ws8、ws11~ws19 等走 ws1 NAT 的主机默认网关保持 10.0.0.11 不变，与现网一致，无需批量改 GATEWAY。
  • ws1 Gb2（业务 10.0.0.11）保持启用；待防火墙策略验证通过后，再择机关闭 ws1 侧 NAT 进程/规则即可，不要求停网卡。
  • 适合：希望割接当晚尽量少动服务器、回滚时仅切回 ws1 NAT 的场景。
方案乙 · 新网关地址

防火墙网关 = 10.0.0.254

10.0.0.254 / 24

  • 在防火墙 GE0/0/7（路由模式）配置 LAN 地址 10.0.0.254/24，作为 B 组新业务网关。
  • ws4、ws8、ws11~ws19 在后续割接步骤中分批将默认网关由 10.0.0.11 改为 10.0.0.254；可灰度、可回滚单台。
  • ws1 Gb2 同样无需停用；在主机全部切至 .254 之前，ws1 与防火墙可短暂并存，注意避免双 NAT 冲突（先配防火墙、再改主机网关）。
  • 适合：希望业务网关与 ws1 业务 IP（.11）解耦、长期由防火墙独占 .254 的场景。

3.3 ws6 主机侧配置（割接当晚）

  1. 备份：现网 /etc/sysconfig/network-scripts/ 或 netplan 配置、iptables、业务监听端口清单。
  2. Gb1（原公网口）：删除公网 IP 182.140.240.121，可改为 down 或仅保留无 IP（避免与防火墙 WAN 冲突）。
  3. Gb2（业务口）：IP 10.0.0.16，掩码 255.255.255.0。
  4. 默认网关：10.0.0.11（方案甲）或 10.0.0.254（方案乙）。
  5. DNS：61.139.2.69（与现网一致）。
  6. 验证：内网 ping 网关 → 外网访问 → 外网回连映射端口；确认不再在 ws6 上 ip addr 看到 182.140.240.121。
注意：公网 IP 只能出现在防火墙 XGE0/0/0 一侧；若 ws6 Gb1 仍配置同网段地址会导致 ARP/路由冲突，割接前必须摘掉。

四、B 组端口转发（承接原 ws1 DNAT）

原 ws1（10.0.0.11）上的 DNAT 需在防火墙上逐条迁移后再停用 ws1 NAT 进程。ws1 Gb2 网卡保持在线。

  1. 在 ws1 导出当前 DNAT/iptables：iptables -t nat -L -n -v 或现网文档。
  2. 在 USG 上为每条规则创建 目的 NAT：公网 IP/端口 → 内网 B 组主机 10.0.0.x:端口。
  3. 若公网入口仍在极云线路（182.140.146.x 段），映射配置在 GE0/0/0/1 透传链路边界或上游极云 FW，需与运营商/极云确认入口；若入口在西信线，则绑在 182.140.240.121。
  4. 配置 trust/untrust 安全策略 放行映射会话。
  5. 灰度验证单条端口后，再批量切换；最后停用 ws1 NAT 服务。

五、推荐配置顺序（割接日）

  1. 备份防火墙与 ws1/ws6 网络配置。
  2. 配置 XGE0/0/0（西信 WAN）并打通 182.140.240.1。
  3. 配置 GE0/0/7（10.0.0.0/24）与 B 组网关（.11 或 .254）。
  4. 配置 ws6：SNAT + 策略路由 + DNAT 端口表。
  5. 修改 ws6 主机：仅保留 10.0.0.16，网关指向防火墙。
  6. 迁移 ws1 DNAT 至防火墙；抽测 B 组与 A 组。
  7. 稳定后停用 ws1 NAT 进程（Gb2 不停网卡）。

六、验证清单

  • XGE0/0/0 ping 通 182.140.240.1 与外网；GE0/0/7 与业务机互通
  • ws6（10.0.0.16）出网源地址为 182.140.240.121
  • 外网访问 182.140.240.121:<端口> 到达 ws6 对应服务
  • ws6 网卡上无 182.140.240.121 地址
  • B 组默认网关与方案甲/乙一致，ws4/ws8/ws11~19 出网正常
  • A 组公网业务不受影响（极云透传）
  • 原 ws1 DNAT 端口已全部在防火墙生效

防火墙接口、网关、ws6 公网映射、B 组端口转发的逐步操作说明见 0.2.4 防火墙改造配置步骤；本节为方案甲/乙割接顺序摘要。

对象操作
线路A、公网 ws1/2/3/5/6/7/dev/dev-2、C06 ws4/ws8（甲：网关不变）不改 / 甲零变更
西信 XGE0/0/0、GE0/0/7 业务网、Sw-B新接线+新配置
ws11~ws19方案甲：网关保持 10.0.0.11；方案乙：分步改为 10.0.0.254
ws1 Gb2两种方案均不停用网卡；NAT 由防火墙承接后择机停 ws1 NAT 进程

割接前在 0.1 节 确定方案甲或方案乙。

方案甲（防火墙 10.0.0.11 · 主机不改网关）

  1. 准备：备份 ws1 DNAT 规则；确认西信 GE7 参数
  2. 预配：XGE0/0/0 接西信骨干；GE0/0/7 配置 10.0.0.11/24（方案甲）
  3. 激活：启用接口；B 组 ping 网关 10.0.0.11（与现网一致）；验证 A 组公网
  4. 验证：抽测 ws11/ws18/ws19 出网；确认无需改主机 GATEWAY
  5. 收尾：防火墙策略稳定后，择机停用 ws1 NAT 进程（Gb2 网卡保持在线）

方案乙（防火墙 10.0.0.254 · 分步改主机网关）

  1. 准备：同方案甲
  2. 预配：XGE0/0/0 西信 WAN；GE0/0/7 配置 10.0.0.254/24（方案乙）
  3. 激活：ping 10.0.0.254；验证 A 组
  4. 灰度：1~2 台 B 组（如 ws18/ws19）将 GATEWAY 改为 10.0.0.254
  5. 批量：ws11~ws17 等分 3~4 批切换
  6. 收尾：全部切至 .254 后停用 ws1 NAT（Gb2 仍保持在线）

回滚：方案甲恢复 ws1 NAT；方案乙单台改回网关 10.0.0.11。防火墙与 ws1 可短暂并行，注意避免双 NAT。
